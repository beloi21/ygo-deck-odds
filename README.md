# Yu-Gi-Oh Deck Builder by A.R.C. Alberto

Opening-hand odds for Yu-Gi-Oh! Master Duel and OCG decks: https://beloi21.github.io/ygo-deck-odds/

This repository only holds the built app that GitHub Pages serves. It is replaced on each release, and a daily job refreshes `banlists.json` (OCG list from YGOPRODeck, Master Duel list from Master Duel Meta). Decks you make in the app are stored in your own browser, not here.
