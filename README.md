# Oh!-Mi-Yu-Gi by A.R.C. Alberto

A Yu-Gi-Oh! OCG collection tracker and deck builder with optimization and shopping: https://beloi21.github.io/ygo-deck-odds/

This repository only holds the built app that GitHub Pages serves. It is replaced on each release, and a daily job refreshes `banlists.json` (the OCG list from YGOPRODeck) and adds images for new cards. Decks you make in the app are stored in your own browser, not here.
